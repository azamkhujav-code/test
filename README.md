# Vite React TypeScript Project

This project is a React application built with Vite and TypeScript, featuring a login component and a home page.

## Getting Started

To get started with this project, follow these steps:

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

## Available Scripts

In the project directory, you can run:

- `npm run dev`: Runs the app in development mode
- `npm run build`: Builds the app for production
- `npm run lint`: Runs the linter
- `npm run preview`: Previews the production build
- `npm test`: Runs the test suite

## Running Tests

To run the unit tests for this project, use the following command:

```
npm test
```

This will run all the tests in the project using Jest and React Testing Library.

## Project Structure

- `src/pages/Login.tsx`: Contains the Login component
- `src/pages/Home.tsx`: Contains the Home component
- `src/pages/Login.test.tsx`: Contains unit tests for the Login component
- `src/pages/Home.test.tsx`: Contains unit tests for the Home component
